# Folienübersicht

`overview.js` verwaltet Raster und Scrollen der gesamten Übersicht. `styles.css` gestaltet die Folienvorschau.

Benötigt die öffentliche Zeichen-Schnittstelle, um Notizvorschauen mitzunehmen. Registriert den Übersichtsmodus und dessen Dock-Befehl.

`module.json` ist die Ressourcenregistrierung. Eigene Beschriftungen liegen in `locales.json`. Nach Quellenänderungen den gemeinsamen Build ausführen; generierte Dateien unter `runtime/` nicht von Hand bearbeiten.
